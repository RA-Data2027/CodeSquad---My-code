# CodeSquad — My Code

A collection of introductory web-development exercises, practice projects, and study notes documenting my progress in HTML, web accessibility, and foundational web concepts.

## About This Repository

This repository brings together my coding practice and review materials as I strengthen my programming and web-development foundations. The projects focus on organizing webpage content, creating forms and tables, embedding media, and considering accessibility.

These are educational exercises rather than production applications.

## Projects

| Project | Description |
| --- | --- |

## Viewing the Exercises

Browse the files directly on GitHub to review the code.

To view an HTML exercise in a browser:

1. Download the relevant file.
2. If the file has no extension, save a local copy with an `.html` extension.
3. Open the file in a web browser.

Review notes and question-and-answer files can be read directly on GitHub.
